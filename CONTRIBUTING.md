# Contributing

Thanks for your interest. This repo holds the marketing site for
[cerid.ai](https://cerid.ai), built with Next.js 16 and deployed on Vercel.

## Development setup

```bash
npm install
npm run dev
```

## What we accept

- Copy fixes, broken links, and typos — straight to PR.
- Accessibility and performance improvements — straight to PR.
- Design or layout changes — open an issue first; the site follows a brand kit
  and unsolicited redesigns won't be merged.

## PR conventions

- **No AI attribution.** Do not add `Co-Authored-By: Claude` / `Anthropic` / any
  other AI tool line to commits, PR titles, or PR descriptions — even if you used
  an AI assistant during development. Commits are authored by humans.
- **One concern per PR.** Small, focused diffs get reviewed fast.
- **Verify locally.** `npm run build` must pass before you open the PR.
